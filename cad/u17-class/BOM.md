**销轴指示长度（按叠层估算，mm）：**

- D 销（斗杆-铲斗铰点）：D耳板(K5,12) + 斗杆衬套(95) + D耳板(12) ≈ 119，另加两侧K5耳衬套凸出13x2 → 全长约 145
- E 销（斗杆-连杆铰点）：臂侧板t10x2(=20)+两侧衬套(95)+连杆内间距(97) 取较大者，估约 L≈97+2*10=117（连杆在外侧）
- G 销（斗连杆-铲斗连杆铰点）：斗连杆t10x2+隔套(75) ≈ 95
- J 销（连杆-连杆铰点）：L1、L2 各t10，叠合处约 20~30，具体按最终装配定
- C 销（斗缸底铰点）：A5耳板t12x2 + 缸底耳宽≤60 → 约 84~90
- A 销：Ø35，取决于动臂本体接口，本设计未涉及，仅给孔位Ø60.5/线镗Ø35H8

> 以上销长均为**估算指示值**，最终以实际叠层复核为准。

## 组焊工艺要点

1. **臂总成**：A1侧板×2先与A2底板、A3顶板、A4后板点固定位组焊成箱形梁；F->B（曲柄顶部）切线段保持开口，为臂缸杆头让位，不封板。A5斗缸耳板焊于臂顶后（跨A3顶板处），A6加强环贴焊于A、B孔外侧。
2. **焊后镗孔**：A(Ø35H8)、D/E(Ø30H8)、C(A5,Ø30H9)、B(Ø30H9) 均为先焊后镗，保证两侧板同轴，孔位公差由镗床保证，不依赖激光切割孔位精度。
3. **刃板坡口**：K3刃板前缘（远离铲斗一侧长边）开30°坡口，与K1侧板/K4底弧板对接焊；可焊接式斗齿座另购另焊，不含在本次设计中。
4. **底弧板卷弧**：K4为t6平板下料，仅在两条MARK基准线之间的区段卷弧至中性层R177（外R180/内R174），两端平直段（连接刃板与顶板的直边）保持不卷，卷弧后与K1侧板、K3刃板、K2顶板组焊。
5. **铲斗总成**：K5耳板立焊于K2顶板上表面（y=-95基准线），K6三角筋板补强K5耳板与顶板/侧板之间的焊缝根部。
6. **理论容量**：铲斗结构容量（型线面积x宽度384）≈ 0.0390 m^3（参考，未计边坡角修正）。

## 运动学核算（详见控制台输出与 preview/assembly_poses.png）

- 油缸可达角度范围 g（满足油缸长度560~860mm，且与g连续覆盖）：**-33° 至 114°**（铲斗回转跨度 147°）
- 对应斗尖角（臂系坐标, = g-90）：**-123.0° 至 24.0°**
- 可达范围内最小传动角：**37.4°**（发生于 g=114°；合格区间[35°,145°]内）
- 斗缸(近似胶囊体)与臂侧板最小间隙：**58.9 mm**（正值=不干涉）
- 铲斗斗体与斗杆（扣除D处R55轮毂圆）：最大重叠 **0.0 mm²**，最小间隙 **33.5 mm**（油缸伸到 860 即为收斗极限；若换 320 行程油缸，收斗到底时斗口会顶到斗杆底板）
- g 最小端 = 油缸全伸 = 收斗到底；g 最大端 = 油缸全缩 = 翻斗卸料到底
